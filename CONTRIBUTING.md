# Contributing to Valstorm

Thank you for your interest in Valstorm!

## 1. Dedicated Development Team & Copyright Policy

Valstorm (`open-api`, `open-worker`, `agent-runtime`, and related ecosystem projects) is developed, maintained, and architected exclusively by the core engineering team at **Valstorm LLC**.

### No External Code Contributions Accepted
To protect intellectual property, prevent code contamination, ensure enterprise architectural integrity, and maintain **100% unified copyright ownership under Valstorm LLC without third-party fragmentation**, **we do not accept external pull requests, code patches, or direct repository contributions from third parties**.

Any Pull Requests (PRs) submitted by external individuals or organizations will be automatically and respectfully closed without merging.

---

## 2. How the Community Can Participate

While we do not accept external code patches, community feedback, discussions, and ecosystem involvement are welcome:

1. **Bug Reports**: If you encounter an unexpected error, reproducible bug, or unexpected behavior, please open an Issue with:
   - A clear description of the issue.
   - Exact steps to reproduce.
   - Operating environment (OS, architecture, Docker version, database version).
   - Sanitized terminal logs and stack traces.
2. **Feature Requests & Ideas**: We value feedback on how Valstorm solves real-world workflow and engineering challenges. Please share your suggestions and architectural use cases in GitHub Discussions or Issues.
3. **Security Vulnerabilities**: If you discover a potential security vulnerability, please do **not** disclose it in a public issue. Report it immediately and privately to `security@valstorm.com`.
4. **Agency & Developer Integrations**: We strongly encourage agencies, dev shops, and third-party developers to build custom modules, connectors, client implementations, and workflows against Valstorm's published APIs, webhooks, and CLI tooling.
