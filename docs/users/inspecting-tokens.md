# Inspecting Token Usage (Users & Operators)

The runtime provides live token telemetry on every turn as well as aggregate session reporting.

---

## 1. Per-Turn Telemetry
After every prompt turn, the runtime prints:
```text
[Usage Stats] Turn Tokens: Prompt=112 | Completion=45 | Total=157
```

- **Prompt Tokens**: The input context (conversation history, system instructions, and tool schemas).
- **Completion Tokens**: Tokens generated by the model (thoughts, tool call arguments, text reply).
- **Total Tokens**: Sum of prompt and completion tokens for this specific turn.

---

## 2. Viewing Cumulative Session Stats
Inside the interactive REPL, type `/stats`:

```text
[gemini-2.5-flash] > /stats

--- Session Token Telemetry ---
Total Messages:     6
Prompt Tokens:      1420
Completion Tokens:  380
Total Tokens:       1800
```

---

## 3. Viewing Message History & Per-Message Models
Type `/history` to see which model generated each message:

```text
[gemini-2.5-flash] > /history

--- Message History (4 messages) ---
1. USER: Calculate 25 * 4
2. ASSISTANT [gemini-2.5-flash] (125 tokens): [Tool Calls: 1]
3. TOOL: 100
4. ASSISTANT [gemini-2.5-flash] (42 tokens): The result of 25 * 4 is 100.
```
